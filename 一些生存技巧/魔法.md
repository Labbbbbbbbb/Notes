## 组策略彻底禁用 WebRTC（企业/高级用户）

适用于 Windows 专业版/企业版。 [![digitash.com](https://www.bing.com/th?id=ODF.G3itlWrpSrzf1kxkwUcIUg)digitash.com](https://digitash.com/microsoft/edge/completely-disable-webrtc-ip-leakage-group-policy-microsoft-edge/)

路径：  
**gpedit.msc → 计算机配置 → 管理模板 → Microsoft Edge**

找到：  
**WebRTC IP handling policy（WebRtcIPHandlingPolicy）**

设置：

- 启用（Enabled）
- 下拉菜单选择：**Disable non-proxied UDP**（最严格）

作用：

- 阻止 WebRTC 通过 STUN/TURN 泄露真实 IP
- 强制所有 WebRTC 流量走代理/VPN
