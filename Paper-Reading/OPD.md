自回归生成模型的Knowledge Distillation问题，主要解决：
current KD methods for auto-regressive sequence models suffer from **distribution mismatch between output sequences seen during training and those generated by the student during inference**
的问题

几种调整的基线对比
**SFT**：输入训练数据中的前序tokens（也是ground truth），用ground truth和和模型生成token做交叉熵损失。模型从未见过自己生成的上下文。并且这里的ground truth是one-hot编码
**Supervised KD**：输入同样是训练数据的前序ground truth token，但是标签是teacher model的生成，来拟合student model的KL散度

> [!NOTE] 
> KD效果一般比SFT要好，因为尽管隔了一层模型，但是SFT中的label是独热编码，信息量有限，不像KD是直接拟合教师模型的概率分布，信息量更大。

**SeqKD**：输入是teacher model生成的前序token，标签和Supervised KD一致

> [!NOTE] 
> SeqKD 试图用 teacher 生成的序列来代替 ground truth，希望 student 能接触到"有瑕疵的"序列。但这里有两个问题：
> 1. Teacher 生成的序列通常质量很高（greedy/beam），和 ground truth 差别不大
> 2. **prefix 还是来自 teacher 的输出，不是 student 自己会产生的输出**——student 推理时会生成 teacher 永远不会生成的错误 token

**On-policy GKD**：输入是student model生成的前序token，**是唯一在训练时就让 model 在自己会访问的状态空间上获得 teacher 反馈的方法**——所以它能修复这个根本性的 mismatch，带来数量级的提升。

> [!NOTE] ps.
> 上述方法中teacher和student model的输入是一样的，然后拟合输出分布。

**GKD 的实际实现：
Step 1: Student 先采样完整序列
```python
# 对 batch 中每个 x
y_S = student.generate(x, temperature=τ)   # 自回归采样出完整序列 ŷ_S = (ŷ_S,₁, ..., ŷ_S,m)
```
Step 2: Teacher 和 Student 各做一次并行 forward pass
```python
# Teacher 输入: (x, ŷ_S)，用 causal mask
# Causal mask 保证 teacher 在位置 t 只能看到 ŷ_S 的前 t-1 个 token（和 student 自回归条件完全一致）
logits_T = teacher.forward(inputs=x + y_S, causal_mask=True)   # 一次 forward，得到所有位置的 soft label

# Student 输入: 同样的 (x, ŷ_S)，同样的 causal mask
logits_S = student.forward(inputs=x + y_S, causal_mask=True)   # 得到 student 在相同 prefix 下的预测

# loss: 逐 position 计算 divergence
loss = f_divergence(logits_T, logits_S, mask_on_y_S)
```
**关键：Teacher 和 Student 看到的输入序列 (x, ŷ_S) 完全相同，只是各自输出自己的 next-token 分布**，然后计算两者之间的 f-divergence 作为 loss。

> [!NOTE] insight
>**KD for auto-regressive sequence models can be viewed as an imitation learning problem with an interactive expert. Using this insight, GKD trains the student on its self-generated sequences that are on-policy, instead of a fixed set of outputs sequences, using teacher probabilities as expert labels on these sequences.**
>
>**"We demonstrate that on-policy GKD can be seamlessly combined with RL fine-tuning (e.g., RLAIF) of language models, a combination that has not been previously explored (Figure 5)."**

### KL Divergence
论文除了提出on-policy这个策略特点之外，还有一部分讨论了这个拟合函数--散度函数的处理

解释他们为什么提供 forward KL / reverse KL / JSD 三种选择
$$
\mathcal{D}_{KL}(P \| Q) = \sum_{c \in \mathcal{C}} P(c) \log \frac{P(c)}{Q(c)}
$$
代表用Q(student)去表达P(teacher)的分布时会损失多少信息。
