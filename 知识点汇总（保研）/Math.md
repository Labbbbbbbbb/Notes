## 1.连续与一致连续/收敛与一致收敛
一致连续:∀ε>0,∃δ>0(只依赖于ε,与x无关),使得对任意 x₁,x₂∈D,只要 |x₁−x₂|<δ,就有 |f(x₁)−f(x₂)|<ε。
一致收敛:∀ε>0,∃N(只依赖于ε,与x无关),使得当 n>N 时,对任意 x∈D,都有 |Sₙ(x)−S(x)|<ε。

连续和一致连续的关系,跟"逐点收敛 vs 一致收敛"是完全平行的结构——区别都在于"控制误差所需的东西能不能跟位置无关"。

**一、连续(在一点连续,进而逐点连续)**

f(x) 在点 x₀ 连续:

∀ε>0, ∃δ>0(依赖于 x₀ 和 ε), 使得 |x−x₀|<δ 时 |f(x)−f(x₀)|<ε

f 在区间 D 上连续,是指对 D 上**每一个** x₀ 都满足上面这条——但 δ 是可以随着 x₀ 变化的。也就是说,同样的误差 ε,在不同的点上,可能需要完全不同大小的 δ 才能保证。

**二、一致连续**

f 在 D 上一致连续:

∀ε>0, ∃δ>0(只依赖于 ε,跟 x 无关), ∀x₁,x₂∈D, 只要 |x₁−x₂|<δ, 就有 |f(x₁)−f(x₂)|<ε

**核心区别就一句话**:普通连续里 δ 可以"看点下菜",一致连续要求存在一个**公共的 δ**,能同时罩住区间里所有的点对。

**三、经典反例:f(x)=1/x 在 (0,1) 上**

这个函数在 (0,1) 上处处连续,但不一致连续。

直观理由:越靠近 x=0,f 变化得越剧烈——想让 |f(x₁)−f(x₂)| 小于给定 ε,所需的 δ 就得越小。取 x₁=1/n, x₂=1/(n+1),这两点间距 →0,但函数值之差 |f(x₁)−f(x₂)|=1 恒定不变。这说明不存在一个统一的 δ 能同时管住区间内所有位置的"陡峭程度",所以不一致连续。

对比 f(x)=x² 在 [0,1](https://claude.ai/chat/%E9%97%AD%E5%8C%BA%E9%97%B4)上,则是一致连续的——因为闭区间是紧的(有界闭),函数的"陡峭程度"在整个区间上有上界,不会像 1/x 那样在某个方向无限恶化。

**四、判断准则(常用、好操作)**

**Lipschitz 条件蕴含一致连续**:若存在常数 L,使得 |f(x₁)−f(x₂)|≤L|x₁−x₂| 对任意 x₁,x₂∈D 成立,则 f 在 D 上一致连续(取 δ=ε/L 即可,跟 x 无关)。

**导数有界蕴含一致连续**:若 f 可导且 |f'(x)|≤M(有界)在区间上成立,由中值定理 f(x₁)−f(x₂)=f'(ξ)(x₁−x₂),满足 Lipschitz 条件,从而一致连续。这也是为什么 1/x 在 (0,1) 上不一致连续——f'(x)=−1/x² 在这个区间上无界。

**Cantor 定理(重要结论)**:闭区间上的连续函数必定一致连续。这是一致连续理论里最核心的定理之一,靠的是闭区间的紧性(有限覆盖定理)。所以区分"连续"和"一致连续"的关键场景,主要出现在**开区间或无界区间**上——闭区间上两者其实是一回事。

收敛与一致收敛：
设函数项级数 Σuₙ(x),部分和 Sₙ(x),定义域 D。

**逐点收敛**:对每个固定的 x∈D,数列 Sₙ(x) 收敛(到 S(x))。也就是说,对每一个 x,单独看 ε-N 关系:

∀x∈D, ∀ε>0, ∃N(依赖于 x 和 ε), 当 n>N 时 |Sₙ(x)−S(x)|<ε

**一致收敛**:N 不依赖于 x,对整个区间"步调一致":

∀ε>0, ∃N(只依赖于 ε), ∀x∈D, 当 n>N 时 |Sₙ(x)−S(x)|<ε

**核心区别**就在于 N 能不能对 x 一致地选出来。逐点收敛是"每个点各自收敛,收敛速度可以不一样、可以任意慢";一致收敛要求"存在一个公共的收敛速度,把所有点罩住"。

一个经典反例:Sₙ(x)=xⁿ 在 [0,1] 上逐点收敛(到 0,x<1 时;到 1,x=1 时),但不一致收敛——越靠近 x=1,想让 |xⁿ−0| 小于给定 ε 所需的 n 就越大,没有一个统一的 N 能同时管住所有 x。

## 泰勒展开的原理是什么

泰勒展开的核心思想是:**用多项式去逼近一个复杂函数,而且要求在某一点附近,多项式跟原函数不仅函数值相同,连各阶导数(反映的变化趋势)也都相同。**

**出发点:为什么要这么做**

多项式是最好算的函数——加减乘除、求值都简单。如果能用多项式代替一个复杂函数(比如 eˣ、sin x、ln(1+x))做近似计算,会非常方便。问题是:怎么找一个"最贴近"原函数的多项式?

**核心原理:导数匹配**

想法是这样的——在点 x₀ 附近,如果一个多项式 P(x) 要逼近 f(x),那么至少应该做到:

- P(x₀) = f(x₀) (函数值相同,起点对齐)
- P'(x₀) = f'(x₀) (变化率相同,趋势对齐)
- P''(x₀) = f''(x₀) (变化率的变化率相同,凹凸对齐)
- ……
- P⁽ⁿ⁾(x₀) = f⁽ⁿ⁾(x₀) (直到 n 阶导数都对齐)

匹配的阶数越多,多项式在 x₀ 附近跟 f(x) 贴合得越紧密——因为越高阶的导数相同,意味着两个函数"变化的变化的变化……"都同步,分开的速度就越慢。

**具体构造**

设 P(x) = c₀ + c₁(x−x₀) + c₂(x−x₀)² + ... + cₙ(x−x₀)ⁿ

逐个对 P 求导并代入 x=x₀,利用 (x−x₀)ᵏ 求 k 阶导数在 x₀ 处等于 k! 、更高次项导数为 0 的性质,可以解出:

cₖ = f⁽ᵏ⁾(x₀) / k!

于是得到:

f(x) ≈ Σₖ₌₀ⁿ [f⁽ᵏ⁾(x₀)/k!]·(x−x₀)ᵏ

这就是泰勒多项式。系数里的 k! 不是随便加的,正是为了抵消求导时链式产生的阶乘因子,从而使得每一项求 k 阶导后代入 x₀ 恰好等于 f⁽ᵏ⁾(x₀)。

**误差(余项)哪里来**

有限阶多项式毕竟不是原函数本身,两者之间有差距,这个差距就是**余项** Rₙ(x) = f(x) − P(x)。

余项的存在本身可以用**柯西中值定理**反复应用来证明并给出具体表达式,比如拉格朗日余项:

Rₙ(x) = f⁽ⁿ⁺¹⁾(ξ)/(n+1)! · (x−x₀)ⁿ⁺¹ (ξ 在 x₀ 和 x 之间)

这个形式跟泰勒多项式的通项长得像,可以理解成:如果余项的规律跟前面各项一致的话,"下一项"大概长这样——只是导数换成了在 (x₀,x) 之间某点 ξ 处取值,而不是固定在 x₀。这保证了余项会随 n 增大、(x−x₀) 变小而趋于零(在合适条件下),从而泰勒多项式确实能越来越逼近 f(x)。

**一句话概括原理**

泰勒展开的本质是:**在一点附近,用"函数值 + 各阶导数信息"重构出一个多项式,使得这个多项式和原函数在该点附近具有相同的局部行为(相同的值、相同的斜率、相同的弯曲程度……),阶数越高,匹配的信息越多,逼近效果越好。**

## 一致收敛与柯西准则的联系

柯西准则的思想是"收敛可以不知道极限是谁,只看自己内部是否越来越靠近",这个思想同样可以搬到一致收敛上,只是要把"逐点的柯西"换成"一致的柯西"。

**逐点收敛的柯西准则**(对每个 x 单独用数列柯西准则):

Sₙ(x) 收敛 ⟺ ∀x, ∀ε>0, ∃N(x,ε), 当 n,m>N 时 |Sₙ(x)−Sₙ(x)|<ε

**一致收敛的柯西准则**:

Sₙ(x) 在 D 上一致收敛 ⟺ ∀ε>0, ∃N(只依赖 ε), ∀x∈D, ∀n,m>N, 都有 |Sₙ(x)−Sₙ(x)|<ε

跟一致收敛定义本身的关系一样:区别还是在于 N 是否跟 x 无关。

**这个准则的价值在哪**

好处是不需要先求出极限函数 S(x) 就能判断一致收敛性——直接看 Sₙ 内部两两之间的距离是否能被"一致地"控制住。这在很多时候比直接用定义(要先知道 S(x) 是什么)方便得多,尤其是判断级数一致收敛时,常写成等价形式:

Σuₙ(x) 一致收敛 ⟺ ∀ε>0, ∃N, ∀x∈D, ∀n>N, ∀p∈ℕ, |uₙ₊₁(x)+uₙ₊₂(x)+...+uₙ₊ₚ(x)|<ε

这个形式是判断一致收敛(比如结合 Weierstrass 判别法)常用的出发点——魏尔斯特拉斯判别法本质上就是通过给出跟 x 无关的控制级数 Mₙ,直接让柯西准则里的余项被 Σ_{k=n+1}^{n+p} Mₖ 控制住,从而绕开对 x 的讨论。

**一句话总结**

逐点收敛的柯西准则是"数列柯西准则对每个 x 分别使用",一致收敛的柯西准则是在此基础上要求 N 对所有 x 统一——这跟一致收敛定义相对于逐点收敛定义的加强方式是完全平行的,可以理解成同一种"一致化"操作分别作用在了"用极限定义收敛"和"用柯西准则定义收敛"这两套等价的框架上。

## 线性变换
线性变换(linear transformation)是**保持向量加法和数乘运算结构的映射**——直观说,就是"变换前后,加法和倍数关系不会被破坏"的那种变换。

**严格定义**

设 V, W 是数域 F 上的向量空间(常见情形取 V=W),T: V→W 是一个映射。如果 T 同时满足以下两条,就称 T 是线性变换:

1. **可加性**:T(**α**+**β**) = T(**α**) + T(**β**),对任意 **α**,**β**∈V
2. **齐次性(数乘不变)**:T(k**α**) = k·T(**α**),对任意 **α**∈V, k∈F

这两条也可以合并写成一条(更常用):

T(k₁**α**+k₂**β**) = k₁T(**α**) + k₂T(**β**)

**直观理解**

线性变换保持的是空间的"线性结构"——具体来说:

- **直线还是直线**:一条直线(或经过原点的直线)变换后仍是直线(或退化成一点)
- **原点固定不动**:因为 T(**0**) = T(0·**α**) = 0·T(**α**) = **0**,所以线性变换必然把零向量映射到零向量
- **等间距关系保持**:如果 **β** 是 **α** 的中点,变换后 T(**β**) 仍是 T(**α**)相关向量的中点(线性组合关系被保留)

**矩阵表示**

在有限维空间中选定基之后,任何线性变换都可以用一个矩阵来表示——这是线性变换最实用的地方。设 **α** 在基下坐标为 x,T(**α**) 在(像空间的)基下坐标为 y,则存在矩阵 A 使得:

y = Ax

这也是为什么线性代数里矩阵运算(矩阵乘法、矩阵求逆等)有明确的几何意义——**矩阵就是线性变换的坐标化身**。矩阵乘法对应的正是线性变换的复合:如果先做变换 T₁(矩阵 A),再做 T₂(矩阵 B),复合变换对应的矩阵是 BA(注意顺序,右边的先作用)。

**常见例子(帮助建立直觉)**

- **旋转**:平面绕原点旋转 θ 角,对应矩阵 [[cosθ,−sinθ],[sinθ,cosθ]]
- **伸缩(数乘)**:kI,把每个向量放大/缩小 k 倍
- **投影**:把三维空间的向量投影到某个平面上
- **微分算子**:D: f(x)↦f'(x),在多项式空间里,D(f+g)=D(f)+D(g),D(kf)=kD(f),所以求导本身就是一种线性变换
- **恒等变换 I** 和**零变换**(把所有向量都映射到 **0**)都是线性变换里的特例

**几个核心概念(围绕线性变换展开的内容)**

- **核(kernel)**:Ker(T) = {**α**∈V | T(**α**)=**0**},反映"哪些向量被压缩没了"
- **像(image/range)**:Im(T) = {T(**α**) | **α**∈V},反映变换后能覆盖到的空间范围
- **秩-零度定理**:dim(Ker T) + dim(Im T) = dim V,这是刻画线性变换"信息损失"程度的核心公式
- **特征值与特征向量**:T(**v**)=λ**v** 描述的是线性变换下"方向不变、只被拉伸"的特殊向量,是理解变换几何本质(比如对角化)的关键
- 在不同基下,同一个线性变换对应相似矩阵(前面提到的 A' = P⁻¹AP)

**一句话总结**

线性变换是数学里"结构保持映射"最基本的一种——它不要求保持长度、角度或形状,但**必须保持向量之间的加法和数乘关系**,这是它跟一般映射(比如任意的函数)最根本的区别。
